# ☁️ CloudCase AI

### Professional Cloud Computing Case Study Generator

CloudCase AI is a web-based application that generates **structured and professional Cloud Computing case studies** from any topic entered by the user.

## ✨ Features

* Generate detailed case studies from any cloud topic
* 15-section academic report structure
* Cloud architecture and data flow
* Security, benefits, challenges and future scope
* Professional A4 report layout
* Firebase Authentication & Firestore
* Case study history
* Print / Save as PDF

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Firebase Authentication
* Firebase Firestore

## 📚 Report Sections

1. Title Page
2. Table of Contents
3. Abstract
4. Introduction
5. Background / Domain Overview
6. Problem Statement
7. Existing System
8. Proposed Cloud Solution
9. Cloud Architecture
10. Technologies & Cloud Service Model
11. Working / Implementation
12. Security & Privacy
13. Benefits
14. Challenges, Applications & Future Scope
15. Conclusion & References

## 🚀 How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Run `index.html` using Live Server.
4. Sign in or register.
5. Enter a Cloud Computing topic.
6. Generate your case study.
